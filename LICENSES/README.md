# Third-Party License Texts

This release pack does not include full third-party license texts because the
exact bundled dependencies are not yet known. Keep complete license texts in
this directory for every third-party component actually copied or bundled in a
release.

A dependency used only as an external runtime or development tool remains under
its own license and is described in `../THIRD_PARTY_NOTICES.txt`. If Python,
pygame, Dolphin, DolRecomp, a font, an icon set, or another component is bundled,
copy the authoritative license and notices from the exact distributed version
into this directory and identify the component in the filename.
